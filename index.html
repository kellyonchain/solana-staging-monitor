How scoring works

Each scan reads recent finalized blocks and looks for transactions that use System Program nonce instructions. Every signal adds points, and the total sets the severity: 5 or more is high, 3 or 4 is medium, below 3 is low. A flag means the pattern deserves a look. It does not mean an attack is happening.

SignalPointsWhat it means
Durable transaction1The transaction starts by advancing a nonce, so it can be signed now and sent later.
