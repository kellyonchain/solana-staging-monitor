# Solana Staging Monitor

Early-warning monitor for attack staging patterns on Solana.

### Focus
- Durable nonce account creation and authority changes
- Multisig configuration changes (especially Squads)

### Goal
Detect quiet preparation steps that often happen before major exploits, giving teams earlier visibility.

Inspired by patterns seen in incidents such as Drift (April 2026).
